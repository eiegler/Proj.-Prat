# 📊 Exploratory Data Analysis of Sales

## 📌 Project Objective
The objective of this project is to analyze the sales history of a company to identify customer behavior patterns, most profitable products, and operational bottlenecks. The solution aims to answer strategic business questions and support decision-making to drive revenue growth.

---

## 🛠️ Technologies Used
- **Python:** Data manipulation and processing (`Pandas`, `NumPy`).
- **Data Visualization:** Chart creation and data storytelling (`Matplotlib`, `Seaborn`).
- **SQL:** Data querying and extraction from relational databases.
- **Jupyter Notebook:** Development environment and analysis documentation.

---

## 💡 Key Learnings & Conclusions
Throughout this project, the following practical skills were consolidated:
- **Data Cleaning & Processing:** Identifying and handling missing, duplicate, and inconsistent data.
- **Exploratory Data Analysis (EDA):** Applying descriptive statistics to extract relevant insights before modeling.
- **Data Storytelling:** Communicating complex analytical findings visually with a clear focus on business value.
